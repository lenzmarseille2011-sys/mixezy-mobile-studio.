# Mixezy Mobile — Android

Projet Android natif (WebView sécurisée) pour accéder à la plateforme SaaS Mixezy Mobile.

- Nom de l’application : **Mixezy Mobile**
- Application ID : `com.mixezy.mobile`
- Version : `0.9.3` (versionCode 3)
- Minimum : Android 7.0 / API 24
- Compilation automatisée : GitHub Actions

## Télécharger le projet de compilation

Utilise le paquet autonome `mixezy-mobile-android-build-kit-v0.9.3.zip` ou copie les dossiers `android/` et `.github/` dans un dépôt GitHub dédié.

Consulte `BUILD-APK-GUIDE.md` pour la compilation, l’installation et la configuration du serveur HTTPS.

**L’archive source n’est pas l’APK compilé.** Le binaire est produit par Android Gradle Plugin dans GitHub Actions ou sur une machine équipée du JDK, Gradle et Android SDK.
